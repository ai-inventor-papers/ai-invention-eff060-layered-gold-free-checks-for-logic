# Gold-Free Faithfulness Metrics for NL-to-FOL Translation

Public web page and paper source for the research on cross-family solver consensus as a gold-free faithfulness metric for natural language to first-order logic translation.

## Layout

- `index.html` — self-contained public web page (GitHub Pages site)
- `interactive.html` — self-contained interactive explainer: charts, a method stepper and an item browser drawn from the run's embedded per-candidate results (linked from `index.html`)
- `paper.tex` — LaTeX source of the paper
- `paper.pdf` — compiled paper
- `references.bib` — bibliography
- `figures/` — all figures used by the paper and the web page
  - `fig2_v0.pdf` / `fig2_v0.png` — main comparison chart (consensus vs judges on Dataset E)
  - `fig3_v0.pdf` / `fig3_v0.png` — consensus advantage by sentence complexity
  - `fig4_v0.pdf` / `fig4_v0.png` — error scatter vs correct convergence histogram
- `workspace/` — scratch folder from the LaTeX build (can be ignored)

## How to view

Open `index.html` in any browser. It is fully self-contained with no external dependencies.
